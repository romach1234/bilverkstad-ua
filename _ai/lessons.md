# Граблі

Що вже ламалось — щоб не наступати вдруге. Свої нові граблі дописувати сюди (скіл `parkovka`, крок 2). Стартові записи
перенесені з репо майстерні, з якого виріс цей: конкретні машини прибрані, лишились правила.

## Сайти й дані

- **HTTP 200 — ще не дані.** Реєстр віддавав сторінку-пустушку з кодом 200 і заглушкою в кожному полі, замість 403.
  Скрипт, що знає, що шукає, перевіряє очікуваний текст на сторінці (`web.get(..., expect=...)`). Новий сайт —
  перевіряти **глибоку** сторінку (деталь, схему), не головну
- **«Сторінка недоступна» — лише після реальної спроби**, з кодом відповіді. Гайд одного разу отримав 🔒 на сторінку
  мануала, яка відкривалась тією ж схемою URL, — і через неї вийшов зворотний порядок робіт
- **Сайт, що ріже скрипти, часто пускає Claude in Chrome** (Cloudflare проходить сам за кілька секунд). Капча, вхід з
  паролем — лише людина. Claude in Chrome **не працює з WSL**, з Windows напряму й з Linux-контейнера — працює
- **Повільний сайт ≠ закритий.** workshop-manuals.com відповідає 60–90 с і віддає 522/524 — тайм-аут 120 с і повтори;
  не дочекались — список посилань оператору, хай збереже MHTML
- **Деяким сайтам потрібен короткий User-Agent** (`Mozilla/5.0`) замість повного браузерного — `web.get` і `freeze.py`
  на 403 пробують його самі
- **Дані в JSON усередині `<script>`.** Перше видобування тексту їх вирізало, фікстура була порожньою — дивитись, де
  на сторінці лежить значення, перш ніж довіряти `.txt`
- **WebSearch YouTube не індексує** — шукати `tools/youtube.py search`. Назва відео бреше про покоління мотора: дивитись
  кадри (`frames`) і транскрипт

## Каталоги й підбір

- **Підбір «під авто» в магазинах бреше.** Магазин двічі видав фільтр VW Group на BMW — у каталозі виробника фільтра BMW
  немає взагалі. Шукати по OE, звіряти з каталогом виробника деталі
- **«Compatibility» / «Substitutions» агрегатора — приклад, не повний перелік, і буває сміття.** Відсутність нашої
  моделі в короткому списку нічого не доводить; доводить присутність або каталог виробника. В «аналогах» масляного
  фільтра траплялися сальники клапанів і болт іншої марки
- **Рівні доказу аплікації:** пошук по номеру — деталь існує · каталог виробника деталі (модель, мотор, kW) — сильно ·
  каталог авто з кодом типу (збіг з VIN) — сильніше · схема по VIN — деталь стоїть саме на цій машині
- **Привід агрегатів залежить від компонування авто, не лише від мотора.** Ремінь «з досвіду» виявився від сусідньої
  моделі з тим самим мотором. Ремені, кронштейни, патрубки — по VIN; перед замовленням — напис на старій деталі
- **Комплект «ГРМ з помпою» в магазині буває від іншої версії мотора** — звіряти склад комплекту з каталогом авто
- **Схема каталогу може бути неповною:** «вузла немає» на одній схемі — ще не висновок; пройти сусідні групи
- **PartSouq не знаходить VIN PSA взагалі, а європейський VIN VAG — часто.** Для VAG — elcats по моделі
  (`tools/elcats.py`), для PSA — підбір по типу TecDoc. Не пропонувати оператору ручну роботу на сайті, не перевіривши,
  що сайт цю марку знаходить
- **Сторінка груп PartSouq без артикулів** — лише список схем; прямі посилання на схеми — `tools/partsouq_links.py`.
  Схема буває ілюстрацією без позицій — `freeze.py` таку відкидає
- **Відповідь іншого LLM — підказка, не джерело.** «За оригінальним каталогом» від чат-бота без посилання — 🟡 у кращому
  разі

## Мануали й моменти

- **Мануал має бути про той самий мотор**: покоління, код, кількість клапанів. Книга «з 2004» описала 16V, а машина —
  8V: болт колінвала інший
- **Моменти мотора з мануалу іншої марки з тим самим мотором — так; моменти кріплень кузова — ні.** Кріплення, подушки,
  кількість болтів залежать від авто
- **Розділ мануала посилається на інші розділи** — пройти їх: там буває порядок, який змінює процедуру
- **Нумерація циліндрів V-подібних моторів — лише за схемою з мануала**, не «за логікою»: виробники нумерують по-різному
- **Зведення двох гайдів в один породжує хибні узагальнення** — варіанти всередині родини розводити розділами, кожен зі
  своїм джерелом
- **Перш ніж брати книгу з бібліотеки під «схожу» версію — пошукати офіційний онлайн-мануал саме під цю**

## Фікстури (`raw/`)

- **`.gitattributes` з `raw/** -text` — першим комітом, до першого файлу в `raw/`.** Інакше git нормалізує CRLF→LF при
  першому `add`, і sha256 у `MANIFEST.tsv` не збігаються назавжди — оригінальних байтів у git уже немає. Після
  `freeze.py` на новому комп'ютері — `verify_raw.py` **після** коміту й `git pull` на іншому
- **Подивитись, чия це сторінка.** Збережена «сторінка оригіналу» виявилась сторінкою аналога — частина тверджень (старий
  номер, комплектність) лишилась непідтвердженою
- **Фікстура доводить і відсутність:** у каталозі фільтра марка ×0, а в контрольній фікстурі тієї ж марки — ×3 (видобування
  працює). Так «не для нашої машини» перестає бути чиїмось висновком
- **Фікстура підтверджує присутність значення, не його сенс** — непрямий висновок так і писати непрямим
- **Малюнок у гайді — шлях від теки `guides/`**, інакше `md2html.py` його не вбудує

## Мої помилки — не повторювати

- **Висновок проти власних цифр.** Перечитувати висновок після таблиці: чи він з неї випливає
- **Перший вибір — деталь, знайдена лише пошуком по OE**, коли в каталозі під машину є інша: перший вибір — з підбору під
  машину, знахідка по OE — альтернатива з позначкою
- **Твердження з розбірки / форуму в гайді без позначки 🟡**, ще й таке, що суперечить своїм фікстурам
- **Час з чужої версії мотора без позначки** — писати, з якої версії взято
- **Дорога заміна без дешевої перевірки перед нею** (кришка, роз'єм, запобіжник) — спершу дешеве
- **«Купувати під варіант не треба»** — варіант кріплення визначає, чи підійде деталь; не спрощувати
- **Зупинитись на «потрібна табличка»**, не звузивши вибір тим, що вже відомо (кВт, об'єм, кондиціонер, рік)
- **Досліджувати те, що оператор знає з практики** — спитати одним рядком дешевше
- **Кошик і `-detali` суперечать одне одному** — після правки одного перечитати інше
- **`git mv -k` на незакомічений файл** мовчки нічого не робить і повертає 0

## Git і синхронізація

- **Хук старту робить `fetch` + `merge --ff-only origin/<гілка>`, не `pull`:** `pull` зливає з `FETCH_HEAD` і ловить
  гонку з автофетчем редактора («Cannot fast-forward to multiple branches»)
- **Робота з двох комп'ютерів:** пуш відхилено — спершу `git pull`, потім пуш; не накопичувати незакомічене
- **Файли між комп'ютерами — через git або `cp`, не Провідником Windows:** той лишає `:Zone.Identifier` поруч із кожним
  файлом
