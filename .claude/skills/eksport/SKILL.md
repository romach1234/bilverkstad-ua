# Експорт іншою мовою

Нотатки ведуться українською, бо так швидше працювати. Але їх регулярно треба комусь віддати: власнику машини,
постачальнику, іншій майстерні, механіку. Такий читач не має git, не знає наших позначок і не повинен бачити
внутрішню кухню (шляхи `raw/`, нотатки для верифікатора, наші уроки).

## Спитати, якщо не сказано

Одним питанням (AskUserQuestion), не трьома:

1. **Що** — файл авто, гайд, кошик / деталі, звіт про виконану роботу. Усе репо — ніколи
2. **Мова** — за замовчуванням із профілю країни `kb/region.md` («Клієнт»); будь-яка інша на запит
3. **Формат:**
   - **HTML** (за замовчуванням для гайдів і для клієнта) — один файл, малюнки вбудовані, відкривається на телефоні
     й у браузері без інтернету, друкується. Робиться з перекладеного `.md` через `md2html.py --lang`
   - **TXT** — коли треба вставити в лист / месенджер або читач хоче простий текст

## Куди

```
cars/<регномер>/export/<назва>.<мова>.md     ← перекладений оригінал (з нього генерується HTML)
cars/<регномер>/export/<назва>.<мова>.html   ← для клієнта
cars/<регномер>/export/<назва>.<мова>.txt    ← простий текст
```

**Лист / повідомлення клієнту** — не в `export/`, а прямо в папку машини:
`cars/<регномер>/<авто>-lyst-<YYYY-MM-DD>.<мова>.txt`. Переклад кошторису чи нотатки, що йде вкладенням, — у `export/`.

`<мова>` — код ISO: `en`, `sv`, `de`, `pl`… Гайд, перекладений під машину, — туди ж: клієнт отримує одну теку.
Не прив'язаний до машини довідник — `export/` у корені. Папка комітиться: на іншому комп'ютері файл уже готовий, і
видно, що саме й коли віддавали.

## Як перекладати

Переклад технічний, не літературний.

1. **Артикули, OE-номери, коди моторів, VIN, коди спецінструменту — не торкатися.** `11428507683`, `N47D20C`, `T10050`,
   `MANN HU 6004 x` однакові всіма мовами. Переклад номера = зламана деталь
2. **Моменти й одиниці — як є** (`20 Nm + 45°`). Місцеві одиниці, які читач прочитає інакше, пояснити в дужках —
   які саме, профіль `kb/region.md` («Клієнт»)
3. **Позначки надійності зберегти.** «Не перевірено на цьому авто», «підтвердити по одометру», 🟢 / 🟡 / 🔴 — в
   перекладі мусять лишитися. Загубити застереження = передати гіпотезу як факт. Під таблицями пояснити позначки
   мовою читача (🟢 official manual · 🟡 forum / video, verify · 🔴 not confirmed)
4. **Терміни — як у мануалі цією мовою.** Англійська: англійський мануал виробника вже лежить у `raw/` — брати його
   слова (timing belt, tensioning pulley, crankshaft arrester), а не дослівний переклад з української. Мова країни —
   устояні майстерні терміни (профіль `kb/region.md`, «Клієнт»)
5. **Цитати з мануалу** (англійською в оригіналі) — у англійській версії лишити як є, в інших мовах — перекласти й
   лишити оригінал у дужках, якщо від формулювання залежить дія

## Що прибрати для клієнта (customer ready)

Перекладаємо **для читача**, не для репо:

- **Шляхи `raw/…`** — у HTML `md2html.py` прибирає сам (у розділі джерел лишаються); у TXT — не переносити
- **Внутрішні нотатки:** «верифікатор», «`verify_values`», «урок», «оператор», посилання на `_ai/`, `kb/`, скіли;
  внутрішні ціни закупки й націнки — **лише якщо оператор не сказав інше**
- **Посилання на інші файли репо** (`../cars/...`, `skoda-...-detali.md`) — замінити текстом або прибрати: у
  клієнта цих файлів немає
- **Розділ «Джерела»** — лишити (клієнт чи інший механік має право бачити, звідки моменти), але коротко: назва джерела,
  рівень довіри, посилання. HTML згортає його сам
- **Відео й малюнки** — лишити: посилання на YouTube з таймкодом і малюнки мануалу (у HTML вбудуються з `raw/`, якщо
  URL малюнка той самий, що в оригіналі — **URL не міняти**)

## Шапка документа

Угорі, мовою читача: назва, авто (регномер, модель, VIN), дата експорту, рядок «Translated from Ukrainian workshop
notes, <дата>» — читач має розуміти походження. Для гайда — один рядок, під який мотор / кузов він писаний.

## HTML

```bash
uv run tools/md2html.py cars/<регномер>/export/<назва>.<мова>.md --lang <мова>
```

`--lang` ставить атрибут `lang`, службові підписи й розпізнає розділ джерел мовою документа (`Sources`, `Källor`,
`Quellen`…). Невідома мова — службові підписи англійською. Перевірити: усі малюнки вбудовані (у HTML немає
«image available online only»), відкрити й переглянути розділи.

## TXT

Markdown-таблиці в `.txt` нечитабельні — розгортати у списки:

```
OIL FILTER
  BMW OE:       11428507683
  Alternatives: MANN HU 6004 x / MAHLE OX 404D / Hengst E204HD218
  Source:       <shop> art. 2000038020, 39.90 <currency>
  Verified:     yes - OE number stated in product description
```

- Заголовки великими літерами з порожнім рядком, без `#`
- Ширина до 78 символів — для експорту нотаток. **Лист клієнту — без жорстких переносів**: абзац одним рядком, пункт
  списку одним рядком. Лист вставляють у пошту / месенджер, і переноси по 78 там рвуть речення посередині (оператор, 2026-10-22)
- Замість `[текст](url)` — текст, URL окремим рядком під ним

## Оригінал змінився

Переклад — знімок на дату. Якщо оригінал (гайд, файл авто) потім виправили — перекласти змінене й перегенерувати
HTML, дату в шапці оновити. Перед тим як віддати клієнту старий експорт, звірити дату з `git log` оригіналу.

## Після експорту

`verify_values.py` на перекладі не запускати (шляхи `raw/` у тексті прибрано навмисно). Закомітити, запушити, сказати
оператору шлях до файлу. Якщо треба поділитися посиланням, а не файлом, — запропонувати опублікувати HTML як сторінку
(Artifact), і зробити це лише після згоди: це передача документа назовні.
