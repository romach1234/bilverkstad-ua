# Індекс гайдів

Шукати тут **за кодом мотора (родиною) і кузовом / платформою** нової машини — перш ніж писати гайд або підбирати
деталі. Правило назв — `CLAUDE.md`. Новий гайд або нова машина під наявний гайд — дописати рядок.

Гайдів поки немає. Де шукати мануали й відео під мотор — `kb/dzherela-artykuliv-ta-danych.md` і скіл `gaid`.
