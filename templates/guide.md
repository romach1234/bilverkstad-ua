## Джерела

**Обов'язковий розділ.** Кожне число в документі — артикул, момент, об'єм, розмір,
інтервал — має бути зводиме до джерела. Без цього документ неперевірюваний:
незалежний верифікатор (`/perevirka`) не має з чим звіряти, і твердження лишається
нічиїм припущенням.

По ходу тексту ставити посилання прямо там, де зроблене твердження. Тут — повний
перелік із рівнем довіри.

| № | Джерело | Що з нього взято | Рівень |
|---|---|---|---|
| 1 |  |  |  |

**Рівні:**

| | |
|---|---|
| 🟢 **Офіційне** | BMW TIS, ISTA, ETK, мануал виробника, каталог виробника деталі |
| 🟡 **Непідтверджене** | форум, агрегатор, продавець, пошукова видача |
| 🔒 **Недоступне** | джерело відоме, але закрите (403, Cloudflare, платна підписка) |

🔒 — це **не** 🟢. Якщо джерело прочитати не вдалося, твердження неперевірене,
і в тексті це має бути видно.
