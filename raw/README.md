# raw/ — заморожені джерела

Тут лежать збережені копії сторінок, проти яких перевіряються твердження в нотатках.

## Навіщо

Твердження «масляний фільтр 11428507683» із посиланням на живий сайт через місяць
стає непідтвердженим: сторінка змінилася, сайт закрився або почав віддавати 403.
Половина каталогів недоступна автоматично вже зараз (PartSouq, exist.ua,
avto.pro, autodoc — Cloudflare і 403).

Помилка в артикулі коштує не грошей за деталь, а **двох тижнів простою машини**,
поки замовлять правильну. Тому доказ лежить у репо, а не за посиланням.

## Чому HTTP 200 — ще не дані

**Шведський реєстр car.info віддавав підставні дані замість помилки** (випадок з репо, з якого виріс цей). Після кількох запитів з однієї
IP сайт перестав віддавати реальну інформацію, але **не повернув 403** — замість
цього прийшла сторінка з HTTP 200, де в кожне поле підставлено `Begränsad åtkomst`,
а в заголовку стоїть `BMW 5 Series Demo, 123hk, 1234`.

Це найнебезпечніший тип збою — виглядає як робоча відповідь і парситься. Тому скрипти
`tools/` перевіряють, що на сторінці є очікуваний текст (`web.get(..., expect=...)`). Висновок загальний: **HTTP 200 не означає правдиві
дані**, кожне джерело потребує перевірки правдоподібності результату.

## Структура

```
raw/
├── MANIFEST.tsv                 — шлях, дата, sha256, спосіб отримання, URL
├── mann-filter/c51001_2026-10-16.html + .txt
├── baza-gai/nomer-aa1234bb_<дата>.mhtml + .txt
├── workshop-manuals/n47-oil-filter-torques_2026-10-16.html + .txt
└── partsouq/<slug>_<дата>.mhtml + .txt      ← зберігає оператор вручну
```

- `<slug>_<дата>.<ext>` — дата у назві обов'язкова: джерело могло змінитися,
  і має бути видно, на яку дату зроблене твердження
- `.txt` поруч — видобутий текст. **Механічна звірка працює по ньому**
- `MANIFEST.tsv` — реєстр із `sha256`: якщо файл підмінили, це видно

## Як додавати

### Доступні сайти — автоматично

```bash
uv run tools/freeze.py <URL> --source mann-filter --slug c51001
```

Сторінка за URL зберігається як **MHTML разом із картинками** — малюнки мануалів (моменти, мітки) відкриваються
офлайн у Chrome/Edge. `--no-assets` — голий HTML без картинок.

Що працює звідки — `kb/dzherela-artykuliv-ta-danych.md`; скрипти `tools/` під сайти мають ключ `--freeze`.

### Недоступні сайти — оператор зберігає вручну

PartSouq, exist.ua, avto.pro, autodoc за Cloudflare — автоматично не беруться. Спершу —
Claude in Chrome (`CLAUDE.md`); не вийшло — оператор зберігає сторінку:

1. Відкрити сторінку в браузері
2. **Зберегти як MHTML** (Ctrl+S → «Веб-сторінка, один файл» / «Webpage, Single File»)
3. Покласти у `downloads/` у корені репо — тека є в репо, але її вміст у `.gitignore`, вона лише
   проміжна. Назва файлу не має значення, браузер хай називає як хоче. Після заморозки оригінал з
   `downloads/` видалити — скрипт друкує команду
4. Зареєструвати:

```bash
uv run tools/freeze.py "downloads/OIL FILTER ELEMENT SET F10-5SR 11428507683 _ BMW Parts _ PartSouq.mhtml" \
    --source partsouq --slug oil-11428507683 \
    --url "https://partsouq.com/en/search/all?q=11428507683"
```

Скрипт сам перейменує за схемою `<slug>_<дата>.mhtml`, порахує sha256 і видобуде
текст. MHTML PartSouq важить ~4 МБ, видобувається ~15 тис. символів — усі значення
на місці, включно з назвою позиції в ETK і переліком аналогів.

`freeze.py` відмовляє (код 3), якщо сторінка — заглушка: перевірка Cloudflare замість змісту або схема PartSouq
без жодної позиції (буває — деякі схеми лише ілюстрація). Обійти — `--force`.

Сторінка груп PartSouq (каталог по VIN) артикулів не має — лише список схем. Прямі посилання на схеми з неї
дає `uv run tools/partsouq_links.py <файл.mhtml> [--grep ...]`.

**MHTML, а не скріншот.** Зі скріншота текст не видобувається, тобто механічно
звірити значення неможливо — PNG лишається тільки візуальним доказом для людини
або моделі. MHTML дає і картинку сторінки, і текст для `grep`.

## Як це перевіряється

```bash
uv run tools/verify_values.py --all
```

Скрипт шукає в документах пари «значення в бектиках + шлях до фікстури в тому ж
рядку» і відповідає, чи стоїть значення у збереженому джерелі:

| | |
|---|---|
| ✅ `OK` | знайдено дослівно |
| 🟡 `OK~` | знайдено після нормалізації (`25 Нм` ↔ `25 Nm`, `11 42 8 507 683` ↔ `11428507683`) |
| ❌ `НЕМА` | **значення у джерелі відсутнє** — помилка в документі або не та фікстура |
| 🔒 `ФІКСТУРИ НЕМА` | шлях указано, файлу немає |

Скрипт **нічого не тлумачить**: він підтверджує присутність значення, не його сенс.
Чи справді ця сторінка про нашу машину, чи момент від того вузла — перевіряє агент
`perevirka` (скіл `/perevirka`), і він цей скрипт перезапускає сам.

## Доказ відсутності

Фікстура дозволяє довести й негативне твердження. `mann-filter/c27009_*.txt`:
SEAT ×7, VW ×7, Cupra ×2, **BMW ×0**. Контроль — у `c51001_*.txt` BMW є 3 рази,
тобто видобування марки працює.

Так «цей фільтр не для нашої машини» перестає бути чиїмось висновком.

## Розмір

HTML сторінок магазинів важать по 200–760 КБ, MHTML з картинками — до кількох МБ. Якщо каталог розростеться — стискати `.html` у `.gz`, лишаючи `.txt` як є,
бо саме по ньому йде звірка.
