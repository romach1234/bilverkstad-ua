# bilverkstad-ua — помічник автомайстерні на Claude Code

**Сподобалось? Задонать на машини зі Швеції — [банка](https://send.monobank.ua/jar/9D4xKuYE1D).**

## Що це

Репо — робоче місце **AI-агента майстерні**. Агент допомагає з тим, що забирає найбільше часу між «машина заїхала» і
«машина готова»:

- прийняти машину за номером або VIN (український реєстр), зібрати типові болячки її мотора;
- підібрати запчастини з перевіркою номерів у каталогах і скласти кошик;
- написати гайд ремонту для телефона: процедура, моменти затяжки, інструмент, відео з таймкодами;
- порахувати роботогодини, скласти кошторис клієнту, перекласти документ іншою мовою;
- вести склад деталей, історію робіт по моделях, журнал рішень.

Це **налаштування Claude Code під майстерню плюс база знань**: правила, скіли (процедура на кожен тип задачі), скрипти,
незалежний верифікатор і пам'ять у git. Модель сама планує кроки й виконує їх інструментами, а людина ставить задачу й
погоджує те, що виходить назовні (купити, замовити, надіслати).

Гайдів і машин у репо немає — вони накопичуються з вашої роботи. Де шукати мануали, каталоги й відео — у
[kb/dzherela-artykuliv-ta-danych.md](kb/dzherela-artykuliv-ta-danych.md) і скілі `gaid`.

## Встановлення

### Windows (основний варіант, без WSL)

Потрібно: [Git for Windows](https://git-scm.com/download/win), [Claude Code](https://claude.ai/download) (VS Code з
розширенням Claude Code або десктоп), Chrome з розширенням Claude (для сайтів, що ріжуть скрипти).

1. Створити своє **приватне** репо на GitHub з цього (кнопка «Use this template» або клон + `git remote set-url`): ваші
   машини й нотатки — не для публіки
2. Склонувати його на комп'ютер, у PowerShell у теці репо:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
   Інсталятор поставить `uv` (Python і бібліотеки), налаштує кирилицю в консолі й запустить перевірку середовища й
   джерел
3. Відкрити теку репо в VS Code (або Claude Code) — хук старту покаже табло

**WSL не підходить:** Claude in Chrome з WSL не працює.

### Linux

Потрібно: Docker, VS Code з розширенням Dev Containers, Chrome з розширенням Claude. Відкрити репо → `Dev Containers:
Reopen in Container` — контейнер збереться сам і запустить ту саму перевірку ([.devcontainer/README.md](.devcontainer/README.md)).
Без контейнера: поставити [uv](https://docs.astral.sh/uv/), `uv sync`, `uv run tools/perevirka_seredovyshcha.py`.

## Після встановлення

Перевірка друкує стан кожного сайту **з вашої мережі** — він може відрізнятися від того, що записано в довіднику (його
складали не з України):

| Стан | Що | Що далі |
|---|---|---|
| ✅ | відкривається, і на сторінці є очікуваний текст | агент читає скриптом |
| ⚠️ | 403 / Cloudflare | агент читає через Claude in Chrome |
| ❌ | немає відповіді | лише ви: зберегти сторінку як MHTML у `downloads/` |

У першій сесії скажіть агенту: **«допиши результат перевірки джерел у довідник і пройди сайти з ⚠️ через Chrome»**.
Повторити перевірку будь-коли: `uv run tools/perevirka_seredovyshcha.py`.

Далі заповнити під себе:

- [CLAUDE.md](CLAUDE.md), розділ «Що за машини» — що за майстерня, які машини, чи повертаються
- [kb/katalog-robit.md](kb/katalog-robit.md) — ставка й роботи, якими ви виставляєте рахунки
- [kb/instrument-maisterni.md](kb/instrument-maisterni.md) — що є з приладів і спецінструменту
- [kb/region.md](kb/region.md) — магазини, якими ви реально користуєтесь
- [kb/manualy.md](kb/manualy.md) — де лежить своя бібліотека мануалів, якщо є

## На чому тримається — контролі

Неправильний артикул — це тижні простою машини, неправильний момент затяжки — зірвана різьба або відкручений на ходу
шків. Тому:

- **Кожне число має джерело** — з посиланням у тому ж рядку і рівнем довіри: 🟢 офіційне, 🟡 форум чи агрегатор,
  🔒 не відкрилось, тобто не перевірено
- **Критичні джерела заморожені** в `raw/` з хешем; скрипти перевіряють, що значення з документа справді є в копії і що
  копія не змінилась ([raw/README.md](raw/README.md))
- **Перевіряє не автор (four-eyes):** перед роботою на машині чи замовленням документ звіряє окремий агент, який бачить
  лише документ і джерела ([_ai/ROLES/VERIFICATION_PROTOCOL.md](_ai/ROLES/VERIFICATION_PROTOCOL.md))
- **Межа дозволеного:** чужі сайти агент лише читає. Купити, замовити, надіслати форму, увійти з паролем — тільки людина
- **Пам'ять у git**, не в голові моделі: стан кожної машини — у її `-stan.md`, табло — `_ai/HANDOFF.md`
- **Система вчиться:** коли щось повторюється або ламається, агент пропонує правку скіла, правил чи скрипта; вносить
  після згоди

## Обмеження

- Магазини ріжуть автоматичний доступ. Що не читається скриптом — агент читає через Chrome, а коли і так не виходить —
  ви зберігаєте сторінку (MHTML)
- Скрипти розбирають верстку сайтів, а не API: після редизайну сайту скрипт треба правити (агент це вміє)
- Реєстр не дає коду мотора — лише паливо, об'єм і кВт; код — з VIN і таблички
- Безкоштовних українських норм годин немає — оцінка з норм виробника, аналогій і вашого фактичного часу
