# Бібліотека мануалів

Свої ремонтні мануали (PDF, скани, HTML-архіви) тримати **поза репо**, у сусідній теці, — не в git: обсяг роздує
репо назавжди, а книги захищені авторським правом і на GitHub їм не місце.

```
../manuals/          відносно кореня репо (назву теки — вписати свою)
```

Структура всередині — по марках: `toyota/`, `vw/`, `mitsubishi/`… У документах посилатися як
`books:toyota/<файл>.pdf, с. N` — шлях від кореня бібліотеки, щоб однаково працювало на кожному комп'ютері.

Мануал — 🟢, якщо він **про той самий мотор** (код, покоління, кількість клапанів — `CLAUDE.md`). Сторінку, з якої
беремо моменти й процедуру, заморозити (`uv run tools/freeze.py <файл.pdf> --page N …`) — тоді верифікатор звірить
без бібліотеки.

**Контейнер (Linux):** бібліотеку змонтувати в `.devcontainer/devcontainer.json` (`mounts`), інакше її там не буде.
Без бібліотеки — одразу сказати оператору й записати у відкриті питання машини, що мануал не звірявся.
