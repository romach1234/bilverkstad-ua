# Профіль країни — Україна

Усе, що залежить від країни: номер авто, реєстр, магазини, валюта, мова клієнта, пастки реєстру. Скіли (`nove-avto`,
`pidbir-detalei`, `eksport`, `propozytsiia`) посилаються сюди, а не прописують країну в собі. Для коду (хук
`tools/hooks/car_context.py`) — `tools/region.json`: шаблон номера, валюта. В іншій країні замінюються ці два файли,
скіли лишаються.

Сайти перевірені 2026-11-15 **не з України** — з вашої мережі може бути інакше. Що реально відкривається у вас —
перевірка джерел після встановлення (`README.md`), результат — у `kb/dzherela-artykuliv-ta-danych.md`.

## Номер авто

- Формат: 2 літери + 4 цифри + 2 літери (`AA1234BB`, `КА0001ВС`). Літери — лише ті, що однаково пишуться кирилицею й
  латиницею (А В С Е Н І К М О Р Т Х), тому `АА1234ВВ` і `AA1234BB` — той самий номер. Тека машини —
  `cars/<номер латиницею малими>/` (`cars/aa1234bb/`); хук сам переводить кирилицю
- Номера немає (машина з-за кордону, транзитні номери, ще не зареєстрована) — гілка «номера немає» в `nove-avto`; у
  заголовку файлу — «машина не зареєстрована в Україні»

## Реєстр: дані авто за номером або VIN

```bash
uv run tools/ua-reiestr.py <НОМЕР або VIN> --freeze --write
```

Скрипт читає [baza-gai.com.ua](https://baza-gai.com.ua/) (агрегатор відкритих даних МВС, 🟡): марку, модель, рік,
**повний VIN**, колір, паливо, кузов, об'єм і історію реєстраційних операцій (дата, номер, ТСЦ, населений пункт) —
без імен власників. `--write` створює файл авто в `cars/<номер>/`. Нічого не знайшов — перевір номер; машина могла
ще не реєструватись в Україні.

**Потужність — відкриті дані МВС.** baza-gai кВт не показує. `--opendata <рік> …` шукає VIN у річних архівах
реєстраційних операцій на [data.gov.ua](https://data.gov.ua/dataset/06779371-308f-42d7-895e-5a39833375f0) (🟢 реєстр):
`POWER_KWT`, `CAPACITY` (см³), `OWN_WEIGHT`, `TOTAL_WEIGHT`. Роки — з дат операцій, які показав baza-gai. Архів року —
50–110 МБ, качається один раз у кеш поза репо. **Держномерів у відкритих даних з 07.2026 немає** — шукається лише VIN.

**Коду мотора реєстр не дає** — лише паливо, об'єм і кВт. Код мотора — з VIN і таблички (`nove-avto`). Об'єм + кВт
звужують вибір до одного-двох моторів, але не замінюють табличку.

**Пробігу реєстр не знає** — лише з одометра.

**VIN.** baza-gai віддає повний VIN на сторінці номера. Не знайшлось — оператор переписує VIN зі скла або з
техпаспорта (свідоцтва про реєстрацію).

**Історія пробігів, ДТП, страховки** — [auto.ria.com/check-car](https://auto.ria.com/uk/check-car/): результат лише в
браузері → Claude in Chrome. Кабінет водія, opendatabot, hsc.gov.ua — 403 або вхід через BankID: лише людина.

## Пастки реєстру — не замовчувати

- **Машина з-за кордону** (перша операція в Україні — «первинна реєстрація ТЗ, ввезеного з-за кордону»): пробіг і
  історія до ввезення невідомі; ринок, для якого робили авто, — з VIN і етикеток (США, Корея, Європа — різні мотори й
  комплектації)
- **Часта зміна власників** (кілька операцій за рік) — перекупи; пробіг перевіряти особливо
- **Колір / кузов / паливо змінювались між операціями** — переобладнання (ГБО, вантажний), питання власнику
- **Ознака «в розшуку»** — роботу не починати, сказати оператору

## Магазини й ціни

Порядок доступу — як скрізь: скрипт → Claude in Chrome → оператор зберігає MHTML.

- **Номер деталі — з оригінального каталогу** виробника авто: elcats (ETKA VAG — `uv run tools/elcats.py`),
  catcar.info, PartSouq (за VIN; Chrome), 7zap (Chrome). Аналоги — з каталогу виробника деталі (MANN —
  `uv run tools/mann.py`) і TecDoc (`uv run tools/ersatzteile.py <OE>`)
- **Ціни й наявність:** [exist.ua](https://exist.ua/) (найбільший; підбір за VIN), [avto.pro](https://avto.pro/)
  (агрегатор продавців), [zapchasti.ria.com](https://zapchasti.ria.com/) (продавці й розбірки) — усі за Cloudflare / WAF:
  **читати через Claude in Chrome**, текст сторінок заморожувати (`CLAUDE.md`). Браузера немає — посилання оператору, він
  скине ціни
- Інші магазини (dok.ua, ukrparts, intercars, elit.ua, vladislav.ua, atl.ua, ostriv24, bi.ua) — статус у довіднику джерел
- **Підбір магазину під машину — гіпотеза**, звіряти по OE
- **Toyota EPC дає два номери:** номер для замовлення і номер, вибитий на деталі («Spec: MARK …») — шукати в магазинах за
  обома
- **Попередні замовлення** на машину (кошики, чеки, накладні) — що вже стояло: факт сильніший за каталог
- **Запасні — шведські сайти, що читаються скриптом** (`tools/biltema.py`, `tools/oem.py` → Trodo, mann-filter): якщо
  українські не відкрились — хоч побачити деталь (фото, розміри, крос-номери). Довідково, не для купівлі
- Валюта — `грн`; ціни магазинів — з ПДВ, якщо магазин не каже інакше

## Клієнт: мова, одиниці, рахунок

- **Мова документа клієнту** — українська за замовчуванням; англійська чи інша — на запит (`eksport`)
- **Терміни** — устояні майстерні: ГРМ, ремінь навісного, помпа, ролик-натягувач, сайлентблок
- **Одиниці:** км, Нм, л; машина з США — милі на одометрі (× 1,609 = км), у документі — обидва
- **Рядок роботи в кошторисі** — назвою з довідника робіт майстерні (`kb/katalog-robit.md`), щоб кошторис збігся з
  рахунком; роботи, якої в довіднику немає, — сказати оператору одним рядком: її варто дописати в довідник
