# Джерела артикулів і даних по авто

Статус — **чи читається автоматично** (скриптом), а не чи сайт узагалі працює. Що ❌ для скрипта — часто
відкривається через Claude in Chrome або в браузері оператора (MHTML у `downloads/` → `tools/freeze.py`).

✅ читається, перевірено на реальній сторінці · ❓ відкривається, але чи дістається потрібний вміст — не перевірено ·
❌ 403 / Cloudflare / WAF · ⛔ не відповідає (гео-блок, сайт лежить) · 🖐 лише в браузері

**Колонка «Перевірено» — дата й звідки.** Початковий стан перевірено 2026-11-15 **не з України** (з ЄС). З вашої
мережі може бути інакше (гео-блок, блокування російських сайтів): `uv run tools/perevirka_seredovyshcha.py` перевіряє
сайти, що мають скрипт або перевірку, і друкує стан — дописати сюди з датою «з нашої мережі».

**Правило: знайшли сайт, що читається, — одразу сюди**, навіть якщо знайшли мимохідь. Нечитабельні теж, щоб
наступного разу не перевіряти заново. Перевіряти **глибоку** сторінку (деталь, схему), не головну — головна часто
віддає 200, а сторінка з номером — 403. Сайт читається скриптом — пишемо під нього скрипт (`CLAUDE.md`).

# Toyota / Lexus

Оригінальний каталог — **EPC**; дзеркала (partsouq, megazip, amayama, toyodiy, 7zap) скрипту номер не дають — partsouq
через Claude in Chrome по VIN працює. **EPC дає два номери:** для замовлення і вибитий на деталі («Spec: MARK …») —
шукати за обома. VIN європейської Toyota — 17 символів (`JT…`); японський ринок — frame number (`KDH200-0012345`).
